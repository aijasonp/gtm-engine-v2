# Feedback — Copy Performance Tracking

Tracks per-sequence-step performance data across all active campaigns. Used by:
- `auto_copy_optimizer.py` to find underperforming steps and generate variant rewrites
- `feedback_loop.py` to compute aggregate performance metrics and update angle library

## Data Flow

1. `reply_monitor.py` writes reply data with campaign_id and sequence_number
2. `feedback_loop.py` reads reply data + Smartlead campaign stats, computes per-step metrics
3. Results update `copy-performance.json`
4. `auto_copy_optimizer.py` reads performance data, identifies steps below median positive rate
5. Variants are generated and saved to `sequences/variants/` for review

## Files

- `copy-performance.json`: Structured performance data per campaign per step
- `weekly-insights.md`: Human-readable weekly summary generated by `feedback_loop.py`
